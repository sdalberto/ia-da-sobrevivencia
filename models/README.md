# models/

Modelos de linguagem `.gguf` (baixados por `preparar-kit`). Você também pode colocar aqui qualquer modelo GGUF compatível com o llama.cpp e escolher com `"model_file"` em `config/settings.local.json`.

Language models in GGUF format (downloaded by the kit preparer). Any llama.cpp-compatible GGUF works.
