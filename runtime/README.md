# runtime/

Motores baixados por `preparar-kit`, um por sistema:

- `llama.cpp/<sistema>/` — servidor do modelo de IA (`llama-server`)
- `kiwix-tools/<sistema>/` — servidor das bibliotecas (`kiwix-serve`)
- `python/<sistema>/` — Python portátil

`<sistema>` = windows-x86_64, windows-arm64, linux-x86_64, linux-arm64, macos-arm64, macos-x86_64.
Também aceita um `llamafile` (executável único) colocado direto nesta pasta.
